## P1 — source_pages: Kde sa strácajú?

### Zistenie

**Nestrácajú sa.** Template `_financials.html` (riadok 458-460) správne renderuje:
```html
{% if latest_stmt.notesRisk.sourcePages %}
<p>Zdroj: Notes, str. {{ latest_stmt.notesRisk.sourcePages }}</p>
{% endif %}
```

**Problém:** `NotesRiskAnalysis.sourcePages` je NULL v DB.

### Prečo je sourcePages NULL?

1. `notes_forensic.py` Pydantic model má `source_pages: Optional[str] = None`
2. LLM prompt (F3-B) inštruuje Chief Auditora aby uvádzal source_pages
3. Ale Notes Forensic agent (F2) **nepoužíva** `source_pages` vo svojom output — toto pole sa má plniť z `pdf_ingestion.get_sliced_pdf_page_range()`
4. **Chýba wiring:** `notes_forensic.py` a `narrative.py` agenti nevolajú `get_sliced_pdf_page_range()` a neukladajú `source_pages` do DB

### Bottleneck: `db_repository.py` → `save_notes_to_db` / `save_narrative_to_db`

Tieto funkcie mapujú `source_pages` z Pydantic modelu do DB. Ale Pydantic model má `source_pages = None` pretože agenti ho nikdy nenastavia.

### Fix

V `pipeline.py` po extrakcii Notes/Narrative nastaviť `source_pages` z `get_sliced_pdf_page_range(sliced_pdf_path)`:

```python
# Po notes_forensic extrakcii
notes_risk.source_pages = get_sliced_pdf_page_range(notes_pdf_path)
# Po narrative extrakcii
narrative.source_pages = get_sliced_pdf_page_range(narrative_pdf_path)
```

## P2 — Score Isolation: Pôvod -5 korekcie

### Zistenie

**Score isolation je architektonicky správny.** `-5` pochádza z `_compute_deterministic_adjustment()` v `verdict_builder.py` (riadok 360).

### Data flow pre Score

```
compute_forensic_scorecard() → total_score (deterministický, 5 pilierov)
  ↓
_compute_deterministic_adjustment() → adj (max -5)
  │  Používa IBA staré polia:
  │  - going_concern_doubts → -3
  │  - litigation_risks → -2
  │  - related_party_transactions → -2 (non-consolidated only)
  │  - contingent_risks → -2
  │  - off_balance_sheet → -1
  │  - CompanyEvent CRITICAL → -3 each (max -6)
  │  Cap: -5
  ↓
final_score = deterministic_score + det_adj (clamped 0-100)
  ↓
llmScoreAdjustment = det_adj (informatívne, uložené v DB)
```

### Pre Danucem

- Algoritmické skóre: 91 (deterministický 5-pilierový model)
- Korekcia audítora: -5 (deterministický adjustment z going_concern/litigation/related_party)
- Finálne skóre: 86

### Čo NEMôže meniť Score

| Komponent | Môže meniť Score? | Dôkaz |
|-----------|:---:|-------|
| `ReportFinding` | ❌ | Nie je súčasť `_compute_deterministic_adjustment` |
| `NarrativeRisk.businessDevelopments` | ❌ | Nie je súčasť adjustment |
| `NarrativeRisk.strengthsAndOpportunities` | ❌ | Nie je súčasť adjustment |
| `NotesRisk.significantInvestments` | ❌ | Nie je súčasť adjustment |
| `NotesRisk.financingActivities` | ❌ | Nie je súčasť adjustment |
